# Fleetbase white-label requirements

## Non-negotiable objective
Tenant customers must experience **Afruheritage powered by Infotech Freight Forwarding** and must not see raw Fleetbase branding.

## What this repository already does
- Afruheritage owns onboarding, approval, launch control, and lifecycle management
- Fleetbase is installed underneath on isolated runner nodes
- Tenant runtime URLs are generated by Afruheritage, not by end-user interaction with the Fleetbase CLI

## What still must be completed before public tenant rollout
1. Replace Fleetbase console title, favicon, visible logo, and support links.
2. Replace default email templates and sender names.
3. Remove or rewrite any visible `fleetbase` product references in browser assets and customer-facing operational email.
4. Review licensing before modifying or distributing branded derivatives.

## Delivery rule
Do not publish a tenant runtime until the white-label review is passed by product, legal, and engineering.
